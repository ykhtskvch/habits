# Что поможет мне сейчас?
Личный мобильный трекер. HTML, CSS и JavaScript, без сборки.
## Запуск
Из корня проекта выполните python3 -m http.server 8000 и откройте http://localhost:8000.
## Разработка
index.html — разметка и стили, app.js — логика и локальная история, body.webp — изображение. Каталог проекта можно разместить на статическом хостинге.
## Требования
PRD-v2.md содержит требования и планы. В опубликованном прототипе простая карта тела уже доступна. Замеры гипотез и часть критериев PRD ещё не реализованы. Вино и вейп запланированы на следующую версию.
## Ручная проверка
Отметьте скроллинг, выберите короткое занятие, завершите его и обновите страницу. Проверьте обе записи в истории. Затем откройте карту тела и смените тип тренировки.
## Совместная работа
Изменения можно обсуждать через pull requests. Эта копия не привязана к публикации в Sites. Записи трекера хранятся в браузере.
